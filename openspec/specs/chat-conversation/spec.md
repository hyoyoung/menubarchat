# 대화 기능 스펙

## 목적

모델과 주고받는 대화. 토큰 단위 실시간 스트리밍, 추론 과정 표시, 중단.

## Requirements

### Requirement: 메시지 전송
Enter(또는 전송 버튼)로 초안을 전송하되, 빈 입력과 응답 스트리밍 중의
입력은 무시한다. 초안은 비워지고 사용자 메시지는 즉시 오른쪽 정렬
말풍선으로 나타난다.

#### Scenario: 텍스트가 있는 상태에서 Enter
- **WHEN** 입력란에 공백 아닌 텍스트가 있고 Enter를 누르면
- **THEN** 메시지가 전송되고 입력란이 비워진다

#### Scenario: 스트리밍 중 전송
- **WHEN** 응답이 스트리밍되는 중 사용자가 Enter를 누르면
- **THEN** 아무것도 전송되지 않는다

### Requirement: 스트리밍 표시
SSE로 응답을 스트리밍하며, `reasoning_content` 델타는 답변 위에 별도의
작은 글씨 회색 말풍선으로, `content` 델타는 답변 본문(기본 크기 말풍선)으로
덧붙이고, 최신 메시지로 자동 스크롤한다. 스트림은 `[DONE]` 데이터 라인에서
끝난다.

#### Scenario: 추론을 동반한 모델 응답
- **WHEN** 모델이 추론 후 본문을 스트리밍하면
- **THEN** 추론이 작은 글씨 말풍선으로 먼저 나타나고 이어 기본 크기
  말풍선으로 답변이 표시되며, 침묵하는 멈춤이 없다

### Requirement: 토큰 소비량 표시
스트림 마지막 청크의 `usage`가 도착하면 해당 어시스턴트 답변 아래에
입력/출력 토큰 수를 작은 캡션으로 표시한다. `usage`가 없는 응답(오류,
중단 포함)은 아무 표시도 하지 않는다.

#### Scenario: 정상 응답 완료
- **WHEN** 마지막 청크에 `usage`의 `prompt_tokens`, `completion_tokens`가 포함되면
- **THEN** 답변 말풍선 아래에 "↑<입력 토큰> ↓<출력 토큰>" 캡션이 표시된다

#### Scenario: 중단된 스트림
- **WHEN** 사용자가 스트림을 중단해 `usage`가 도착하지 않으면
- **THEN** 토큰 수 캡션 없이 부분 텍스트만 남는다

### Requirement: 추론 말풍선 접기
추론 말풍선은 기본적으로 앞 5줄만 표시하고, 말풍선 맨 아래 한 줄에
"More" 라벨을 둔다. 바로 앞 사용자 메시지에 페이지 ID가 있으면 라벨은
"More, ID<n>"처럼 ID를 함께 표시한다. 추론이 5줄 이하면 전체를 표시하고
라벨 없다. "More"를 클릭하면 전체 추론이 펼쳐지며 라벨이 "Less"(페이지가
있으면 "Less, ID<n>")로 바뀌고, "Less"를 클릭하면 다시 접힌다. 펼침
상태는 앱 재시작 시 유지되지 않는다.

#### Scenario: 긴 추론 접기
- **WHEN** 추론이 5줄을 넘으면
- **THEN** 앞 5줄과 그 아래 "More" 라벨 한 줄만 표시되고 답변 본문이 화면을 차지하지 않는다

#### Scenario: More/Less로 펼치고 접기
- **WHEN** "More"를 클릭하면 전체 추론이 표시되고 라벨이 "Less"로 바뀌며, "Less"를 클릭하면 다시 접힌다

### Requirement: 중단
중단 버튼을 클릭하면 진행 중인 스트림을 취소하고, 지금까지 받은 부분
텍스트는 유지한다.

#### Scenario: 스트리밍 중 사용자가 중단
- **WHEN** 스트리밍 중 중단 버튼을 클릭하면
- **THEN** 스트리밍이 끝나고 부분 텍스트가 오류 없이 남는다

### Requirement: 답변 복사
어시스턴트 답변 말풍선 하단(본문 한 줄 아래 오른쪽)에 항상 작은 복사
아이콘이 표시된다. 클릭하면 답변 전문이 클립보드에 복사되고 1초간 체크
아이콘으로 바뀐다. 사용자 메시지와 추론 말풍선에는 없다.

#### Scenario: 답변 복사
- **WHEN** 답변 말풍선 하단의 복사 아이콘을 클릭하면
- **THEN** 답변 전문이 클립보드에 복사되고 아이콘이 잠시 체크로 바뀐다

### Requirement: URL 단독 입력 처리
사용자 메시지가 URL 하나뿐이거나 긴 붙여넣기(10줄 초과)면 그 메시지가
마지막 메시지인 요청의 `content` 끝에 지시문을 덧붙인다. 지시문 뒤에는
사용자가 이미 명시적인 지시를 남겼다면 그것이 우선한다는 단서
(`— unless the user already asked something specific above`)가 붙는다.
지시문 기본값은 `summarize it in <시스템 기본 언어>`이며 설정에서
편집한다. 비어 있으면 덧붙이지 않는다. 말풍선 표시는 원문 그대로다.

#### Scenario: URL만 입력
- **WHEN** 사용자가 URL만 붙여넣어 보내면
- **THEN** 요청에 기본 지시문이 포함되어 모델이 요약으로 답한다

#### Scenario: 긴 붙여넣기
- **WHEN** 사용자가 긴 텍스트만 붙여넣어 보내면
- **THEN** URL과 동일하게 기본 지시문이 요청에 포함된다

#### Scenario: 사용자 지시와 함께 붙여넣기
- **WHEN** 사용자가 자신의 지시(예: "원인 찾아줘")와 함께 긴 텍스트를 붙여넣으면
- **THEN** 기본 지시문보다 사용자 지시가 우선 적용된다

#### Scenario: 지시문 변경
- **WHEN** 설정에서 지시문을 "translate to Korean"으로 바꾸고 URL만 보내면
- **THEN** 모델이 번역으로 답한다

### Requirement: 지우기
휴지통 버튼을 클릭하면 대화를 모두 지운다.

### Requirement: 오류 표시
2xx가 아닌 HTTP 응답은 "Error:"로 시작하는 어시스턴트 스타일 메시지로,
상태 코드와 응답 본문(잘림)과 함께 표시한다. 실패한 스트림이 남긴 빈
자리 메시지는 먼저 제거한다.

#### Scenario: API가 400을 반환
- **WHEN** 엔드포인트가 요청을 거부하면
- **THEN** "Error: HTTP 400: {본문}" 말풍선이 표시된다

### Requirement: 웹 페이지 읽기
사용자 메시지에 `http(s)` URL이 포함되면 전송 전에 **첫 번째 URL 1개**의
페이지를 내려받아 본문 텍스트(HTML → 텍스트 변환, 최대 2만 자)를 추출한다.
단, 긴 붙여넣기(10줄 초과) 메시지에 포함된 URL은 가져오지 않는다.
가져온 페이지에는 통합 첨부 카운터로 `ID<n>` ID를 부여하고, 미리보기
말풍선(og:image 썸네일 + ID<n> + 도메인 + 본문 첫 줄)을 표시한다.

본문은 그 페이지가 붙은 사용자 메시지가 마지막 메시지인 요청에만 해당
메시지 `content` 끝에 덧붙는다. 이후 요청에서는 해당 메시지 자리에
`[Page ID<n> (<도메인>) — mention "ID<n>" to re-include]` 스텁만 담는다.
마지막 사용자 메시지가 `ID<n>`을 언급하면 해당 ID의 본문을 그 요청에 다시
덧붙인다. 가져오기 실패 시 미리보기 말풍선에 간결한 오류("HTTP <코드>",
"timeout", "network error", "no content", "invalid URL")를 표시하며 본문과
스텁 모두 담지 않는다.

#### Scenario: URL을 포함한 질문
- **WHEN** 사용자가 URL과 함께 질문을 보내면
- **THEN** 첫 번째 URL의 본문이 그 요청에 포함되고 미리보기 말풍선에 ID가 표시되며, 모델이 그 내용을 근거로 답한다

#### Scenario: 이후 질문에서 본문 생략
- **WHEN** 페이지가 첨부된 메시지 이후 새 질문을 보내면
- **THEN** 이전 페이지 본문은 전송되지 않고 스텁만 담긴다

#### Scenario: ID 언급으로 재포함
- **WHEN** 이후 질문에 이전 페이지의 ID(예: "ID1")를 언급하면
- **THEN** 해당 페이지 본문이 그 요청에 다시 포함된다

#### Scenario: 긴 붙여넣기 안의 URL
- **WHEN** 10줄 초과 붙여넣기 텍스트 안에 URL이 포함되어 있으면
- **THEN** 해당 URL의 페이지를 가져오지 않고 붙여넣은 텍스트만 전송된다

#### Scenario: 페이지 접근 실패
- **WHEN** URL이 존재하지 않거나 15초 안에 응답하지 않으면
- **THEN** 미리보기 말풍선에 간결한 오류가 표시되고 본문은 전송되지 않는다

### Requirement: 긴 붙여넣기 접기
사용자 메시지가 10줄을 초과하면 접힌 카드로 표시한다: 문서 아이콘 +
첫 줄(한 줄 말줄임) + "붙여넣은 텍스트 · N줄 · ID<n>p". 카드 아래
More/Less(이탤릭)로 전문을 펼치고 접는다. 긴 붙여넣기에는 통합 첨부
카운터로 `ID<n>p` ID를 부여한다.

전문은 그 메시지가 마지막 메시지인 요청에만 `[Pasted text ID<n>p]` 태그와
함께 담고, 이후 요청에서는 해당 메시지 자리를
`[Text ID<n>p (<첫 줄>) — mention "ID<n>p" to re-include]` 스텁으로 대체한다.
마지막 사용자 메시지가 `ID<n>p`을 언급하면 해당 전문을 그 요청에 다시
덧붙인다.

#### Scenario: 긴 텍스트 붙여넣기
- **WHEN** 사용자가 10줄 초과 텍스트를 붙여넣어 보내면
- **THEN** 접힌 카드(첫 줄 + 줄 수 + IDp ID)로 표시되고 첫 요청에 전문이 포함된다

#### Scenario: 이후 질문에서 전문 생략
- **WHEN** 긴 붙여넣기 이후 새 질문을 보내면
- **THEN** 이전 전문은 전송되지 않고 스텁만 담긴다

#### Scenario: IDp 언급으로 재포함
- **WHEN** 이후 질문에 "ID1p"을 언급하면
- **THEN** 해당 전문이 그 요청에 다시 포함된다
