# 메뉴 막대 상주 기능 스펙

## Purpose

앱은 macOS 메뉴 막대에만 존재한다: 아이콘 하나, 채팅 패널, 우클릭 메뉴.
그 밖의 것은 화면에 절대 나타나지 않는다.

## Requirements

### Requirement: 메뉴 막대 아이콘
앱은 `ellipsis.bubble` 심볼의 시스템 상태 항목 하나만 표시하며, 실행 시
Dock 아이콘이나 그 외 어떤 창도 나타나지 않는다.

#### Scenario: 실행 시 화면 구성
- **WHEN** 앱을 실행하면
- **THEN** 메뉴 막대 상태 항목 하나만 나타나고 Dock 아이콘이나 창은 나타나지 않는다

### Requirement: 채팅 패널 토글
좌클릭하면 앱을 활성화한 뒤 아이콘 아래에 채팅 패널을 표시하고, 패널이
실제로 보이는 상태에서 다시 좌클릭하면 숨기며 설정 섹션 상태를 초기화한다.
패널 플래그는 표시됨이지만 화면에 보이지 않는 경우(가려짐·다른 화면)에는
숨기지 않고 아이콘 아래에 재배치해 다시 표시한다. 패널은 모든 Space에
참여하는 크기 조절 가능한 floating `NSPanel`로, 아이콘이 속한 화면의
경계로 클램프해 아이콘 아래 중앙에 위치하고 표시될 때 입력란에 키보드
포커스를 가진다.

#### Scenario: 패널 토글
- **WHEN** 상태 항목을 좌클릭하면
- **THEN** 패널이 아이콘 아래에 나타나 입력란에 포커스가 가고, 다시 좌클릭하면 숨겨지며 설정 섹션 상태가 초기화된다

#### Scenario: 비활성 상태에서 복귀
- **WHEN** 다른 앱을 쓰다가(앱 비활성) 상태 항목을 한 번 클릭하면
- **THEN** 첫 클릭에 패널이 아이콘 아래에 표시된다 (클릭 두 번 불필요)

### Requirement: 우클릭 메뉴
우클릭하면 "About MenuBarChat"과 "Quit MenuBarChat"(Cmd+Q) 컨텍스트
메뉴를 표시한다. About은 표준 정보 패널 대신 앱 이름 구성(Menu Bar +
Chat)과 설명, 버전을 담은 미니 팝업을 아이콘 아래에 띄우며 Close 버튼으로
닫는다. Quit은 앱을 종료한다.

#### Scenario: About 팝업
- **WHEN** 우클릭 메뉴에서 "About MenuBarChat"를 선택하면
- **THEN** 아이콘 아래에 앱 정보 미니 팝업이 뜨고 Close 버튼으로 닫는다
