# Spec Delta

## ADDED Requirements

### Requirement: 붙여넣기 형식 제한
입력란에 붙여넣을 수 있는 것은 텍스트뿐이다. 10줄 이하 텍스트는 초안에
삽입한다. 10줄 초과 텍스트는 붙여넣는 즉시 별도의 붙여넣기 항목으로
승격되어(첫 줄과 줄 수 표시, 삭제·초안 되돌리기 가능) 입력란은 비워
둔다. 전송 시 이 항목이 본문이 되어 긴 붙여넣기 접기 규칙(`ID<n>p`)을
따르고, 초안에 입력이 남아 있으면 개행으로 이어 붙여 함께 전송한다.
텍스트를 동반하지 않은 이미지·파일 붙여넣기는 거부되고 짧은 안내가
표시되며, 텍스트와 함께 있으면 텍스트만 취한다. 설정 섹션이 열려 있을
때는 이 제한을 적용하지 않는다.

#### Scenario: 긴 텍스트 붙여넣기
- **WHEN** 10줄을 초과하는 텍스트를 붙여넣으면
- **THEN** 붙여넣기 항목이 즉시 표시되고 입력란은 비어 있으며, 전송 시
  전문이 `ID<n>p` 첨부로 처리된다

#### Scenario: 이미지 붙여넣기 거부
- **WHEN** 텍스트 없이 이미지만 붙여넣으면
- **THEN** 아무것도 삽입되지 않고 텍스트만 지원한다는 안내가 잠깐
  표시된다
