# Spec Delta

## MODIFIED Requirements

### Requirement: 메시지 복사
어시스턴트 답변 말풍선 하단 오른쪽에 항상 작은 복사 아이콘을 표시한다.
사용자 말풍선은 마우스를 올렸을 때만 오른쪽 아래 모서리에 겹쳐 표시한다
(공간을 차지하지 않아 말풍선 크기는 변하지 않는다). 클릭하면 해당 메시지
전문이 클립보드에 복사되고 1초간 체크 아이콘으로 바뀐다. 추론 말풍선에는
없다. 말풍선 텍스트는 드래그 선택을 제공하지 않는다 — 복사는 복사
아이콘으로만 한다.

#### Scenario: 답변 복사
- **WHEN** 어시스턴트 말풍선의 복사 아이콘을 클릭하면
- **THEN** 메시지 전문이 클립보드에 복사되고 아이콘이 1초간 체크로 바뀐다

#### Scenario: 말풍선 클릭은 무해
- **WHEN** 어시스턴트 말풍선 텍스트를 클릭하면
- **THEN** 선택 레이아웃이 일어나지 않고 말풍선이 공백으로 떨어지지
  않는다
