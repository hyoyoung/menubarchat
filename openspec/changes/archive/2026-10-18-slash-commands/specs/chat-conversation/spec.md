# Spec Delta

## ADDED Requirements

### Requirement: 커스텀 슬래시 명령
입력창 초안이 `/`로 시작하면 설정에 저장된 명령 중 접두 일치 항목을
입력창 위 드롭다운에 표시한다. 드롭다운에서 명령을 선택하면 초안의
`/명령` 토큰이 해당 프롬프트 템플릿으로 전개되고 나머지 초안은 개행으로
이어 붙는다. 드롭다운이 떠 있는 동안 Tab 키를 누르면 첫 번째 일치
명령이 적용된다. 드롭다운 없이 `/명령`을 그대로 전송해도 전송 시점에 같은
전개가 적용된다. 전개는 텍스트 치환이며 그 이후 전송·첨부·스트리밍
동작은 일반 메시지와 동일하다. 일치하는 명령이 없으면 `/` 텍스트는
그대로 전송된다.

#### Scenario: 명령 자동완성
- **WHEN** 초안을 `/ne`까지 입력하면
- **THEN** `news` 명령이 드롭다운에 표시되고 이를 선택하면 초안이 해당
  프롬프트로 전개된다

#### Scenario: 직접 전송 전개
- **WHEN** `/news`를 입력하고 그대로 전송하면
- **THEN** 전개된 프롬프트가 사용자 메시지로 전송된다

#### Scenario: Tab 완성
- **WHEN** 자동완성 드롭다운이 떠 있는 동안 Tab을 누르면
- **THEN** 첫 번째 일치 명령의 프롬프트로 초안이 전개된다

#### Scenario: 미등록 명령
- **WHEN** 저장되지 않은 `/foo`를 전송하면
- **THEN** 텍스트 `/foo`가 그대로 전송된다
