# Spec Delta

## MODIFIED Requirements

### Requirement: 인라인 마크다운 표시
어시스턴트 답변 말풍선은 인라인 마크다운(굵게, 기울임, `코드 범위`, 링크)을
스타일로 렌더링하며 스트리밍 중에도 도착 즉시 반영한다. 블록 요소(코드
펜스, 목록, 제목)는 스타일 없이 원문 텍스트로 표시한다. 취소선(`~~`)은
렌더링하지 않는다(기호는 소비되고 내용만 표시된다). 파싱이 실패한
답변은 원문 그대로 표시한다.

#### Scenario: 스트리밍 중 강조 렌더링
- **WHEN** 답변에 `**굵게**` 같은 인라인 마크다운이 포함되면
- **THEN** 기호 대신 스타일로 표시된다

#### Scenario: 취소선 미렌더링
- **WHEN** 답변에 `~~기호~~`가 줄바꿈을 포함해 나타나면
- **THEN** 어떤 줄에도 취소선이 그어지지 않고(기호는 소비됨) 다른
  인라인 스타일은 유지된다
