# 제안: 웹 페이지 미리보기 말풍선

## 왜

페이지 첨부가 작은 텍스트 캡션이라 무엇이 들어왔는지 한눈에 안 보이고,
가져오기 실패가 조용히 무시돼 원인을 알 수 없다.

## 무엇을

- URL당 본문 가져오기를 메시지당 **첫 번째 URL 1개**로 제한한다.
- 사용자 말풍선 아래 **미리보기 말풍선**을 넣는다: `og:image` 썸네일(있을
  때) + 도메인 + 본문 첫 줄. og:image는 HTML에서 `og:image` 메타 태그를
  직접 파싱한다(의존성 없음).
- 가져오기 실패 시 조용히 넘기지 않고 미리보기 말풍선에 간결한 오류를
  표시한다: "HTTP 404" / "timeout" / "network error" / "no content".
  실패한 페이지는 API content에 덧붙지 않는다.

## 스펙 델타 요약

- chat-conversation — 웹 페이지 읽기 MODIFIED: 1개 제한, 미리보기
  말풍선(og:image+첫 줄), 실패 시 간결한 오류 표시
