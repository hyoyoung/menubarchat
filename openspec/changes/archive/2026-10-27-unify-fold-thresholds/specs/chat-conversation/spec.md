# Spec Delta

## MODIFIED Requirements

### Requirement: 긴 붙여넣기 접기
10줄을 초과하는 붙여넣기 텍스트는 전송 즉시 접힌 카드(첫 줄
말줄임 + "붙여넣은 텍스트 · N줄")로 표시하고 More/Less로 펼친다. 붙여넣기
첨부가 아닌 사용자 메시지도 줄바꿈 5개를 초과하거나 100자를 초과하면 같은
접힌 카드로 표시한다(첨부가 아니므로 ID 없는 라벨). 접힘
라벨은 추론 말풍선과 같은 형식으로 첨부일 때 ID를 오른쪽에 함께 표시한다
("More, ID<n>p"). 통합 첨부 카운터로 `ID<n>p`를 부여한다. 전문은 그
메시지가 마지막 메시지인 요청에만 `[Pasted text ID<n>p]` 태그와 함께
담고, 이후 요청부터는 `[Text ID<n>p (<첫 줄>)]` 스텁으로 대체한다 —
첨부 분류(pasteID 부여)는 기존대로 10줄 초과 시에만 이루어진다.

#### Scenario: 긴 붙여넣기 카드
- **WHEN** 사용자가 10줄을 초과하는 텍스트를 붙여넣어 보내면
- **THEN** 접힌 카드로 표시되고 그 요청에만 `[Pasted text ID<n>p]` 태그와 함께 전문이 전송된다

#### Scenario: 접힘 라벨의 ID
- **WHEN** 접힌 붙여넣기 카드의 More/Less 라벨을 보면
- **THEN** 라벨 오른쪽에 `ID<n>p`가 표시된다

#### Scenario: 길면 첨부가 아니어도 접힘
- **WHEN** 10줄 이하(첨부 아님)지만 줄바꿈 5개를 초과하거나 100자를
  초과하는 텍스트를 전송하면
- **THEN** ID 없는 "붙여넣은 텍스트 · N줄" 접힌 카드로 표시되고 전송
    내용은 일반 메시지 그대로다

#### Scenario: 긴 명령 메시지는 접지 않음
- **WHEN** `{previous}` 주입 등으로 명령 전개 메시지가 10줄을 초과하면
- **THEN** 붙여넣기 카드로 접히지 않고 명령 메시지로 표시된다

### Requirement: 추론 말풍선 접기
모델의 추론 텍스트는 기본적으로 접힌 카드("More, ID<n>")로 표시하고
펼치면 전문을 보여준다. 접는 기준은 줄바꿈 5개 초과 또는 100자 초과다 —
그 미만은 그대로 표시한다. ID는 통합 첨부 카운터를 따른다.

#### Scenario: 긴 추론 접기
- **WHEN** 추론이 줄바꿈 5개를 초과하거나 100자를 초과하면
- **THEN** 접힌 카드("More, ID<n>")로 표시되고 More/Less로 펼친다

#### Scenario: 추론 접힘
- **WHEN** 답변에 추론 텍스트가 포함되면
- **THEN** 접힌 카드로 표시되고 More/Less로 펼친다

#### Scenario: 짧은 추론은 그대로
- **WHEN** 추론이 줄바꿈 5개 이하이고 100자 이하면
- **THEN** 접힘 없이 전문이 표시된다
