## ADDED Requirements

### Requirement: 웹 페이지 읽기
사용자 메시지에 `http(s)` URL이 포함되면 전송 전에 페이지를 내려받아
본문 텍스트(HTML → 텍스트 변환, 최대 2만 자, URL당 최대 2개)를 추출하고,
해당 사용자 메시지의 API `content` 끝에 덧붙인다. 말풍선 표시는 원문
그대로 두고, 첨부된 페이지는 사용자 말풍선 아래 작은 캡션(도메인)으로
표시한다. fetch 실패나 URL 부재 시 아무것도 덧붙지 않는다.

#### Scenario: URL을 포함한 질문
- **WHEN** 사용자가 URL과 함께 질문을 보내면
- **THEN** 앱이 페이지 본문을 내려받아 요청 컨텍스트에 포함하고, 모델이 그 내용을 근거로 답한다

#### Scenario: 페이지 접근 실패
- **WHEN** URL이 존재하지 않거나 15초 안에 응답하지 않으면
- **THEN** 첨부 없이 원문 텍스트만 전송되고 오류 말풍선은 생기지 않는다
