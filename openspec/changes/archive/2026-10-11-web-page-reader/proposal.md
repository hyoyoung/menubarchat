# 제안: URL 웹 페이지 본문 읽기(web reader)

## 왜

web_search는 검색일 뿐 특정 페이지를 정확히 읽지 못한다. 사용자가
daverupert.com 같은 URL을 물어보면 모델이 내용을 모른 채 답한다. 이
에이전트의 web_reader 도구처럼, 메시지의 URL을 앱이 직접 fetch해 본문을
컨텍스트에 넣으면 된다.

## 무엇을

- 사용자 메시지에서 `http(s)://` URL을 감지하면(최대 2개, 15초 타임아웃)
  페이지를 내려받아 본문 텍스트로 변환한다. HTML→텍스트 변환은 AppKit의
  `NSAttributedString(html:)` 사용 — 서드파티 의존성 없음.
- 추출 본문(최대 2만 자)은 말풍선 표시와 별도로 `Message.pageText`에
  저장하고, API 요청의 해당 사용자 메시지 `content` 끝에 덧붙인다.
  대화에 남아 이후 턴에서도 모델이 페이지 내용을 기억한다.
- 사용자 말풍선 아래 작은 캡션(링크 아이콘 + 도메인)으로 페이지가
  첨부됐음을 표시한다.
- fetch 실패 시 조용히 건너뛴다 — URL이 텍스트로만 전송되는 현재
  동작으로 되돌릴 뿐이다.
