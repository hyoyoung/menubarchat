# Spec Delta

## MODIFIED Requirements

### Requirement: 웹 페이지 읽기
10줄 이하 사용자 메시지에 `http(s)` URL이 포함되면 전송 전에 페이지를
내려받아 본문 텍스트(HTML → 텍스트 변환, 페이지당 최대 2만 자)를
추출하고 통합 첨부 카운터로 `ID<n>`을 부여한다. 일반 사용자 메시지는
첫 번째 URL 1개만 가져온다. 커스텀 슬래시 명령으로 전개된 메시지는 URL
전부를 가져온다 — 최대 10개(11번째부터는 가져오지 않고 무시), 동시에
2개까지만 병렬로 내려받는다(완료되는 대로 다음 URL 투입). 미리보기
말풍선(og:image 썸네일 + ID + 도메인 + 본문 첫 줄)을 페이지별로 표시한다.

본문은 그 메시지가 마지막 메시지인 요청에만 덧붙는다. 일반 메시지의
단일 페이지 첨부는 전문으로 실는다(기존 방식). 명령 전개 메시지의 다중
페이지 첨부는 페이지당 앞 4천 자 발췌로 실고 메시지 첨부 합계는 2만 자
상한(초과 시 페이지별 비례 축소)으로 제한한다. 전문은 보관하여 언급
재포함 때 사용한다. 이후 요청부터는 해당 메시지 자리를
`[Page ID<n> (<도메인>)]` 스텁으로 대체한다. 가져오기 실패 시 해당
페이지의 미리보기 말풍선에 간결한 오류("HTTP <코드>", "timeout",
"network error", "no content", "invalid URL")를 표시한다.

#### Scenario: 긴 붙여넣기 안의 URL
- **WHEN** 10줄 초과 붙여넣기 텍스트 안에 URL이 포함되어 있으면
- **THEN** 해당 URL을 가져오지 않고 붙여넣은 텍스트만 전송된다

#### Scenario: 일반 메시지는 첫 URL만
- **WHEN** 일반 사용자 메시지에 여러 URL이 포함되어 전송되면
- **THEN** 첫 번째 URL 1개만 fetch되고 나머지 URL은 텍스트로 남는다

#### Scenario: 명령 전개 메시지의 다중 URL
- **WHEN** 커스텀 슬래시 명령으로 전개된 메시지에 여러 URL이 포함되어
  전송되면
- **THEN** 각 URL의 페이지가 ID를 받아 내려받아지고(동시 2개), 마지막
  메시지 첨부는 페이지당 발췌로 합계 상한 내에 실린다

### Requirement: 첨부 ID 언급 재포함
마지막 사용자 메시지가 첨부 ID(예: "ID1", "ID2p")를 언급하면 해당 첨부의
전문을 그 요청에 다시 덧붙인다. 페이지(ID<n>)의 경우 요약 첨부가 발췌였더라도 재포함은 전문으로 실는다. 여러 ID는 모두 덧붙고 이미 포함된 첨부는
중복하지 않는다.

#### Scenario: 첨부 ID 재언급
- **WHEN** 마지막 사용자 메시지가 첨부 ID(예: "ID1")를 언급하면
- **THEN** 해당 첨부의 전문이 그 요청에 다시 덧붙여진다

### Requirement: 응답 대기 표시
스트리밍이 진행 중이고 마지막 메시지가 어시스턴트 답변이 아니거나
어시스턴트 답변의 본문이 비어 있으면, 답변이 올 자리에 어시스턴트
말풍선과 같은 형태의 대기 표시(작은 스피너)를 전송 직후부터 표시한다.
추론만 도착한 동안에는 추론 말풍선 아래 답변 자리에 표시한다. 페이지
가져오기 중에는 스피너 옆에 문구를 함께 표시하고, 가져올 페이지가
2개 이상이면 "페이지 N개 가져오는 중…", 1개면 "페이지 가져오는 중…"
문구를 쓰며, 가져오기가 끝나면 문구만 빠진다. 첫 답변 델타가 도착하거나
스트림이 오류로 끝나면 대기 표시는 사라지고 실제 답변 또는 오류 표시로
이어진다.

#### Scenario: 첫 토큰 대기
- **WHEN** 사용자가 메시지를 보내고 첫 답변 델타가 아직 도착하지 않았으면
- **THEN** 답변 자리에 스피너 대기 표시가 나타나 있다

#### Scenario: 답변 시작
- **WHEN** 첫 답변 델타가 도착하면
- **THEN** 대기 표시가 사라지고 그 자리에서 실제 답변이 스트리밍된다

#### Scenario: 페이지 가져오기 중 대기
- **WHEN** URL 메시지 전송으로 페이지를 가져오는 중이면
- **THEN** 대기 말풍선에 스피너와 함께 가져오기 문구(가져올 페이지가
  2개 이상이면 "페이지 N개 가져오는 중…")가 표시된다

#### Scenario: 추론 후 답변 대기
- **WHEN** 추론이 도착했지만 답변 본문의 첫 델타가 아직 도착하지 않았으면
- **THEN** 추론 말풍선 아래 답변 자리에 스피너 대기 표시가 나타나 있다
