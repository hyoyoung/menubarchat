# Spec Delta

## MODIFIED Requirements

### Requirement: 기본 지시문
사용자 메시지가 URL 하나뿐이거나 긴 붙여넣기(10줄 초과)면, 그 메시지가
마지막 메시지인 요청의 `content` 끝에 설정의 지시문을 `[Instruction:
<지시문> — unless the user already asked something specific above]` 형태로
덧붙인다. 지시문 텍스트의 `{language}`는 전송 시점에 Language 설정의
언어명으로 치환한다. 지시문이 비어 있으면 덧붙이지 않고, 말풍선 표시는
원문 그대로다. 기본값과 편집은 설정 스펙을 따른다.

#### Scenario: URL만 입력
- **WHEN** 사용자가 URL만 붙여넣어 보내면
- **THEN** 기본 지시문이 적용되어 모델이 요약으로 답한다

#### Scenario: 사용자 지시와 함께 붙여넣기
- **WHEN** 사용자가 자신의 지시(예: "원인 찾아줘")와 함께 긴 텍스트를 붙여넣으면
- **THEN** 기본 지시문보다 사용자 지시가 우선 적용된다

### Requirement: 커스텀 슬래시 명령
입력창 초안이 `/`로 시작하면 설정에 저장된 명령 중 접두 일치 항목을
입력창 위 드롭다운에 표시한다. 드롭다운에서 명령을 선택하거나 드롭다운이
떠 있는 동안 Tab 키를 누르면 초안의 `/…` 토큰이 완성된 `/명령` 이름으로
바뀐다(이름 뒤 공백 포함). 나머지 초안은 그대로 유지된다. 프롬프트
전개는 전송 시점에만 적용된다 — 드롭다운 없이 `/명령`을 그대로 전송해도
같은 전개가 적용되고, 전개된 프롬프트의 `{language}`는 Language 설정의
언어명으로 치환된다. 전개는 텍스트 치환이며 그 이후 전송·첨부·스트리밍
동작은 일반 메시지와 동일하다. 일치하는 명령이 없으면 `/` 텍스트는
그대로 전송된다. 전개된 프롬프트는 그 메시지가 마지막 메시지인 요청에만
전문으로 실리고, 이후 요청부터는 해당 메시지 자리를
`[Command: /<이름>]` 스텁으로 대체한다(지시문·URL 목록 미포함, 페이지
스텁은 기존대로 함께).

#### Scenario: 명령 자동완성
- **WHEN** 초안을 `/ne`까지 입력하면
- **THEN** `news` 명령이 드롭다운에 표시되고 이를 선택하면 초안 토큰이
  `/news`로 완성된다

#### Scenario: 직접 전송 전개
- **WHEN** `/news`를 입력하고 그대로 전송하면
- **THEN** 전개된 프롬프트가 사용자 메시지로 전송된다

#### Scenario: Tab 완성
- **WHEN** 자동완성 드롭다운이 떠 있는 동안 Tab을 누르면
- **THEN** 초안 토큰이 첫 번째 일치 명령의 `/이름`으로 완성된다

#### Scenario: 미등록 명령
- **WHEN** 저장되지 않은 `/foo`를 전송하면
- **THEN** 텍스트 `/foo`가 그대로 전송된다

#### Scenario: 과거 명령 메시지 스텁화
- **WHEN** `/news` 실행 후 이후 요청에서 과거 명령 메시지를 구성하면
- **THEN** 해당 자리는 `[Command: /news]` 스텁으로 대체되고 전개 프롬프트
  전문·URL 목록은 실리지 않는다

#### Scenario: 언어 치환
- **WHEN** `{language}`를 포함한 명령 프롬프트가 전개되면
- **THEN** `{language}`가 Language 설정의 언어명으로 바뀌어 전송된다
