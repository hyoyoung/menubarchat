# 제안: 통합 첨부 ID 체계와 긴 붙여넣기 접기 카드

## 왜

10줄 넘는 텍스트를 붙여넣으면 말풍선이 화면을 채워 대화가 밀린다. 접어서
보여주고 전문은 첫 요청에만 보내면 된다. 아울러 기존 페이지 ID(`ID1`)와
새 붙여넣기 ID의 체계를 통일한다.

## 무엇을

- **통합 ID 체계**: 모든 첨부(웹페이지, 긴 붙여넣기)가 세션 증가 카운터를
  공유하고 타입 글자가 붙는다 — 웹페이지 `ID1`, 붙여넣기 `ID2p`. 언급
  규칙도 이 형식(`ID<n>`, `ID<n>p`)으로 통일한다. 기존 `ID<n>` 페이지
  표기는 `ID<n>`으로 바뀐다(미리보기 카드, More/Less 라벨, 스텁, 재포함
  규칙 모두).
- **긴 붙여넣기 접기**: 사용자 메시지가 10줄 초과면 접힌 카드로 표시 —
  `doc.text` 아이콘 + 첫 줄(한 줄 말줄임) + `붙여넣은 텍스트 · N줄 ·
  ID<n>p`. 카드 아래 More/Less(이탤릭)로 펼침/접음.
- **전송 절약**: 긴 붙여넣기 전문은 그 메시지가 마지막인 요청에만
  `[Pasted text ID<n>p]` 태그와 함께 담고, 이후 요청에서는
  `[Text ID<n>p (<첫 줄>) — mention "ID<n>p" to re-include]` 스텁으로
  대체한다. 언급 시 재포함은 웹페이지와 동일 규칙.
