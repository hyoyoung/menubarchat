# Spec Delta

## MODIFIED Requirements

### Requirement: 메시지 전송
Enter(또는 전송 버튼)로 초안을 전송하되 빈 입력은 무시한다. 초안은
비워지고 사용자 메시지는 즉시 오른쪽 정렬 말풍선으로 나타난다. 사용자의
직접 전송(Enter·전송 버튼·대기 항목 "지금 보내기")은 바닥 팔로우를
재개한다. 응답
스트리밍 중 Enter는 초안을 대기열(최대 3개, FIFO)에 넣고 초안을 비운다.
대기열이 가득 찬 상태에서 Enter를 누르면 무시하고 초안을 유지한다. 대기
메시지는 스트림이 끝나는 즉시(완료·중단 무관) 첫 항목부터 순차 자동으로
전송되며, 이때 바닥 팔로우는 변경하지 않는다 — 팔로우 중이면 계속
따라가고, 사용자가 읽던 위치가 있으면 유지된다. 대기
목록이 화면에 표시된다. 각 대기 항목은 즉시 전송(현재
응답을 끊고 바로 전송), 삭제, 초안 되돌리기로 조작할 수 있고 전체 해제도
할 수 있다.

#### Scenario: 스트리밍 중 전송
- **WHEN** 응답이 스트리밍되는 중 사용자가 Enter를 누르면
- **THEN** 메시지가 대기열에 들어가고 스트림 종료 직후 자동 전송된다

#### Scenario: 대기 중 추가 입력
- **WHEN** 대기 메시지가 3개 찬 상태에서 다시 Enter를 누르면
- **THEN** 무시되고 초안은 그대로 남는다

#### Scenario: 대기 메시지 즉시 전송
- **WHEN** 대기 항목에서 즉시 전송을 선택하면
- **THEN** 현재 응답이 중단되고 대기 메시지가 바로 전송된다

#### Scenario: 대기열 순차 전송
- **WHEN** 스트리밍 중 3개를 대기시키고 스트림이 끝나면
- **THEN** 첫 항목이 즉시 전송되고 이후 스트림 종료마다 남은 항목이
    순서대로 자동 전송된다

#### Scenario: 자동 전송은 스크롤 위치 유지
- **WHEN** 스트림 종료 후 대기 메시지가 자동 전송될 때 사용자가 위로
  올라가 읽고 있으면
- **THEN** 스크롤 위치는 유지되고 바닥으로 점프하지 않는다 — 직접
    전송(Enter·전송 버튼·지금 보내기)만 바닥 팔로우를 재개한다
