# Spec Delta

## MODIFIED Requirements

### Requirement: 응답 대기 표시
스트리밍이 진행 중이고 마지막 메시지가 어시스턴트 답변이 아니거나
어시스턴트 답변의 본문이 비어 있으면, 답변이 올 자리에 어시스턴트
말풍선과 같은 형태의 대기 표시(작은 스피너)를 전송 직후부터 표시한다.
추론만 도착한 동안에는 추론 말풍선 아래 답변 자리에 표시한다. 페이지
가져오기 중에는 스피너 옆에 "페이지 가져오는 중…" 문구를 함께 표시하고,
가져오기가 끝나면 문구만 빠진다. 첫 답변 델타가 도착하거나 스트림이
오류로 끝나면 대기 표시는 사라지고 실제 답변 또는 오류 표시로 이어진다.

#### Scenario: 첫 토큰 대기
- **WHEN** 사용자가 메시지를 보내고 첫 답변 델타가 아직 도착하지 않았으면
- **THEN** 답변 자리에 스피너 대기 표시가 나타나 있다

#### Scenario: 답변 시작
- **WHEN** 첫 답변 델타가 도착하면
- **THEN** 대기 표시가 사라지고 그 자리에서 실제 답변이 스트리밍된다

#### Scenario: 페이지 가져오기 중 대기
- **WHEN** URL 메시지 전송으로 페이지를 가져오는 중이면
- **THEN** 대기 말풍선에 스피너와 함께 가져오기 문구가 표시된다

#### Scenario: 추론 후 답변 대기
- **WHEN** 추론이 도착했지만 답변 본문의 첫 델타가 아직 도착하지 않았으면
- **THEN** 추론 말풍선 아래 답변 자리에 스피너 대기 표시가 나타나 있다
