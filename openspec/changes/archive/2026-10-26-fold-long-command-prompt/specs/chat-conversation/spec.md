# Spec Delta

## MODIFIED Requirements

### Requirement: 커스텀 슬래시 명령
입력창 초안이 `/`로 시작하면 사용 가능한 명령(앱에 내장된 기본 명령 +
저장된 사용자 명령) 중 접두 일치 항목을 입력창 위 드롭다운에 표시한다.
이름이 같으면 기본 명령이 우선한다. 드롭다운에서 명령을 선택하거나
드롭다운이 떠 있는 동안 Tab 키를 누르면 초안의 `/…` 토큰이 완성된
`/명령` 이름으로 바뀐다(이름 뒤 공백 포함). 나머지 초안은 그대로
유지된다. 프롬프트 전개는 전송 시점에만 적용된다 — 드롭다운 없이
`/명령`을 그대로 전송해도 같은 전개가 적용되고, 전개된 프롬프트의
`{language}`는 Language 설정의 언어명으로, `{previous}`는 뉴스 다이제스트
이력으로 치환된다. 전개는 텍스트
치환이며 그 이후 전송·첨부·스트리밍 동작은 일반 메시지와 동일하다.
일치하는 명령이 없으면 `/` 텍스트는 그대로 전송된다. 전개된 프롬프트는
그 메시지가 마지막 메시지인 요청에만 전문으로 실리고, 이후 요청부터는
해당 메시지 자리를 `[Command: /<이름>]` 스텁으로 대체한다(지시문·URL
목록 미포함, 페이지 스텁은 기존대로 함께). 줄바꿈 5개를 초과하거나
100자를 초과하는 명령 전개 메시지는 접힌 카드("명령 /<이름> · N줄")에
메시지 앞 5줄 미리보기를
담아 표시하고 More/Less로
펼친다 — 이때 페이지 묶음이 있으면 More/Less 라벨 오른쪽에 묶음
ID("More, ID<n>")를 함께 표시한다(붙여넣기 분류·fetch·전송 규칙은
무관). 내장 명령 `previous-news`와
`clear-previous-news`는 예외로 프롬프트 전개 대신 로컬 동작을 수행한다 —
`previous-news`는 뉴스 다이제스트 이력의 최신 항목을 어시스턴트 말풍선으로
표시하며(요청·fetch·스트리밍 없음, 이력이 비었으면 안내 말풍선),
`clear-previous-news`는 이력 링 전체를 비우고 확인 말풍선("이전
다이제스트 이력을 지웠습니다.")을 표시한다(이후 `/news`의 `{previous}`는
"none"으로 시작). 둘 다 스트리밍 중에는 무시되고, 표시된 항목은 이력에
다시 저장되지 않는다.

#### Scenario: 명령 자동완성
- **WHEN** 초안을 `/ne`까지 입력하면
- **THEN** `news` 명령이 드롭다운에 표시되고 이를 선택하면 초안 토큰이
  `/news`로 완성된다

#### Scenario: 직접 전송 전개
- **WHEN** `/news`를 입력하고 그대로 전송하면
- **THEN** 전개된 프롬프트가 사용자 메시지로 전송된다

#### Scenario: Tab 완성
- **WHEN** 자동완성 드롭다운이 떠 있는 동안 Tab을 누르면
- **THEN** 초안 토큰이 첫 번째 일치 명령의 `/이름`으로 완성된다

#### Scenario: 미등록 명령
- **WHEN** 저장되지 않은 `/foo`를 전송하면
- **THEN** 텍스트 `/foo`가 그대로 전송된다

#### Scenario: 과거 명령 메시지 스텁화
- **WHEN** `/news` 실행 후 이후 요청에서 과거 명령 메시지를 구성하면
- **THEN** 해당 자리는 `[Command: /news]` 스텁으로 대체되고 전개 프롬프트
  전문·URL 목록은 실리지 않는다

#### Scenario: 언어 치환
- **WHEN** `{language}`를 포함한 명령 프롬프트가 전개되면
- **THEN** `{language}`가 Language 설정의 언어명으로 바뀌어 전송된다

#### Scenario: 기본 명령 이름 우선
- **WHEN** 사용자가 기본 명령과 같은 이름의 명령을 저장하면
- **THEN** 드롭다운과 전개 모두 기본 명령이 사용된다

#### Scenario: 이전 다이제스트 다시 표시
- **WHEN** `/previous-news`를 전송하면
- **THEN** 요청 없이 즉시 이력의 최신 다이제스트가 어시스턴트 말풍선으로
  표시되고, 이력이 비어 있으면 안내 말풍선이 표시된다

#### Scenario: 이력 비우기
- **WHEN** `/clear-previous-news`를 전송하면
- **THEN** 요청 없이 이력 링이 비워지고 확인 말풍선이 표시되며, 다음
  `/news`의 `{previous}`는 "none"으로 치환된다

#### Scenario: 긴 명령 메시지 접기
- **WHEN** `{previous}` 주입 등으로 명령 전개 메시지가 10줄을 초과하면
- **THEN** 앞 5줄 미리보기를 담은 접힌 카드("명령 /news · N줄")로 표시되고
  More/Less로 펼치며 fetch·전송 동작은 변하지 않는다 — 페이지 묶음이
  있으면 More/Less 라벨 오른쪽에 `ID<n>`이 함께 표시된다

#### Scenario: 짧지 않은 단문 프롬프트도 접기
- **WHEN** 줄바꿈 없는 한 문단이라도 100자를 넘는 명령 프롬프트(예: 이력
  없는 첫 /news 전개)를 전송하면
- **THEN** 접힌 카드로 표시되어 전문이 화면을 채우지 않는다
